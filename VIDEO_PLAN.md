# Demonstration video plan — under 3 minutes

Target length: 2 minutes 30 seconds. Language: English. No third-party music or trademarks.

1. 0:00–0:20 — Show the project name, Windows host and QNX SDP 8.0 SDK root.
2. 0:20–0:45 — Run the automated unit tests and show all three passing.
3. 0:45–1:15 — Run the SDK inspection. Show the qcc driver, QNX headers and both architecture front-ends.
4. 1:15–1:55 — Build AArch64 and x86_64 probes. Show the two PASS evidence records and SHA-256 hashes.
5. 1:55–2:20 — Inspect ELF headers and show the AArch64 and x86-64 machine identifiers.
6. 2:20–2:30 — If QEMU runtime passes, show the QNX 8.0 booted target and probe output. Otherwise do not imply runtime success; record the runtime stage as pending and do not submit until the target demonstration is complete.

Recording must show the actual running software, not slides or simulated output.
